## 금지

<!-- GitHub에 쓰지 않고 앱 코드·테스트를 수정하거나 구현하지 않는다. Issue의 보고·추정과 확인 사실을 혼합하거나 원인·정책·범위·응답을 임의로 확정하지 않는다. 민감정보를 산출물에 기록하지 않고, PR draft를 생성하거나 사람의 승인을 받은 것처럼 표시하지 않는다. -->

## 출력

<!-- Issue의 번호·URL·updatedAt, 읽은 경로, 확인 사실과 출처, 가설과 확인 방법, 미확인·사람 결정 사항을 구분해 기록한다. plan 경로와 PR draft handoff 경로, 중단 조건 및 재개에 필요한 결정·근거를 남긴다. Issue 본문을 복제하지 않는다. 착수 조건이 충족되면 `docs/prompts/planner.md`와 `docs/templates/implementation-plan.md`를 적용해 지정된 plan을 작성하고 승인 대기 상태로 둔다. -->

## 검증

<!-- Issue 접근과 요청 내용·완료 기준을 확인하고 관련 정책·현재 코드·테스트와 탐색 근거를 대조한다. Issue를 읽을 수 없거나, 필요한 정책이 없거나 충돌·보류되거나, 완료 기준이 없거나, 민감정보가 발견되거나, 사람 결정이 필요한 경우 해당 의존 작업 전에 멈춘다. 누락·충돌·미확인 내용과 필요한 결정 또는 안전한 재개 조건을 기록한다. 실행하지 않은 확인은 통과로 표시하지 않는다. -->

## Handoff
