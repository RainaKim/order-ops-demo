# 환각 방지 체크리스트

코드·의존성·타입·실행 결과를 실제 근거로 확인하고, 확인하지 못한 가정은 구현 또는 보고에서 사실처럼 다루지 않기 위한 체크리스트입니다. 각 항목의 상태가 `확인 필요`이면 변경을 진행하거나 완료로 보고하지 않습니다.

- [ ] **코드에 실제로 존재하는 API만 사용한다.** 호출하려는 함수·메서드·속성이 선언 또는 구현되어 있는지 확인한다.
  - 상태: `확인 필요`
  - 확인 위치: `____________________`
  - 확인 근거(선언·구현·검색 결과): `____________________`

- [ ] **필요한 패키지와 모듈이 실제로 설치·연결되어 있다.** import 대상, `package.json`, lockfile, 현재 모듈 경로를 대조한다.
  - 상태: `확인 필요`
  - 확인 위치: `____________________`
  - 확인 근거(패키지명·버전·경로): `____________________`

- [ ] **type과 function signature를 호출 문맥과 대조한다.** 인수 개수·타입, 반환값, 동기/비동기 여부, 사용 가능한 옵션을 선언부에서 확인한다.
  - 상태: `확인 필요`
  - 확인 위치: `____________________`
  - 확인 근거(선언 또는 타입 정의): `____________________`

  - 상태: `확인 필요`

  - 상태: `확인 필요`

## 미확인 사항 관리
